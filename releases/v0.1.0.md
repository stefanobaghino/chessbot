First release: the Rust UCI engine with the handcrafted evaluation (the configuration that scored 71% against Stockfish at UCI_Elo 2000) and the Lichess bot client.

Behaviour:
- The bot accepts standard-chess challenges at bullet, blitz, rapid and classical speeds, one game at a time by default.
- On SIGTERM or SIGINT it declines new challenges, finishes games in progress, then exits 0; a second signal exits immediately.
- `bin/chessbot-engine bench 10` is the smoke test; `uci` reports `id name chessbot-engine v0.1.0 net:<sha256 prefix>` identifying the embedded net (the placeholder net in this release means the handcrafted evaluation is used).

Environment variables (all read by `python -m bot.lichess_bot`):
- `LICHESS_TOKEN` (required): bot account token with bot:play, challenge:read, challenge:write.
- `DOTENV_PATH`: path of a .env file to load, default `<package>/.env`; variables already set in the environment win.
- `ENGINE_PATH`: engine binary, default `engine/target/release/chessbot-engine` relative to the package; set it to `bin/chessbot-engine`.
- `ENGINE_HASH`: hash size in MB, default 128.
- `MAX_GAMES`: concurrent games, default 1.
- `SHUTDOWN_TIMEOUT`: seconds to wait for games after a signal before resigning them, default 900.
